Тикет — номер из аргументов (`/start N`). Владелец в чате не отвечает: вопросы по тикету — только
`scripts/b0/ticket ask N "вопрос" "вариант 1" "вариант 2"`, в чат — ни одного.

Из главного чекаута запусти `scripts/b0/ticket start N` и дальше делай ровно то, что он печатает
(задание и строку «Дальше:»), до строки «Конец маршрута». Вызовы `scripts/b0/ticket` — с Bash
timeout 1800000: внутри ревью и ожидание мёржа.
