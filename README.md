# workflow-sandbox

Песочница процесса агентной разработки ([канон — `alexkabchina-arch/workflow`](https://github.com/alexkabchina-arch/workflow)).
На ней гоняются сквозной каркас канона и контрольные сценарии (обычный тикет, неподтверждённый критерий,
красный CI, новый коммит после ревью, повторный запуск после сбоя, попытка выйти за полномочия).

Приложение — CLI, считающее сумму заказа со скидкой:

```bash
python -m sandbox 3x100 1x49.90 --discount 10
python -m sandbox 3x100 1x49.90 --discount 10 --kop   # 31491 — итог в копейках, без «₽»
python -m sandbox 3x100 1x49.90 --count   # вторая строка «позиций: 4» — сумма количеств
python -m sandbox 3x100 1x49.90 --loyal   # 332.41 ₽ — скидка постоянного клиента 5 %; с --discount — бо́льшая из двух
python -m sandbox --version   # sandbox 0.1.0
```

Команды, CI и критичные зоны — в профиле [docs/agents/](docs/agents/).


Цена позиции — неотрицательная, не точнее копейки (`1x0.005` — ошибка, без округления), до 15 цифр.

## Флаги

- `--code` — вместо знака «₽» печатается код валюты `RUB` через обычный пробел: `python -m sandbox 3x100 --code` → `300.00 RUB`. Разделитель тысяч остаётся неразрывным пробелом; с `--kop` знака нет, флаг ничего не меняет.
