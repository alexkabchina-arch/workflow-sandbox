# workflow-sandbox

Песочница процесса агентной разработки ([канон — `alexkabchina-arch/workflow`](https://github.com/alexkabchina-arch/workflow)).
На ней гоняются сквозной каркас канона и контрольные сценарии (обычный тикет, неподтверждённый критерий,
красный CI, новый коммит после ревью, повторный запуск после сбоя, попытка выйти за полномочия).

Приложение — CLI, считающее сумму заказа со скидкой:

```bash
python -m sandbox 3x100 1x49.90 --discount 10   # скидка — целое число процентов
python -m sandbox 3x100 1x49.90 --discount 10 --kop   # 31491 — итог в копейках, без «₽»
python -m sandbox 3x100 1x49.90 --count   # вторая строка «позиций: 4» — сумма количеств (не число строк)
python -m sandbox 3x100 1x49.90 --avg   # вторая строка «средняя цена: 87.48 ₽», см. «Флаги»
python -m sandbox 3x100 1x49.90 --loyal   # 332.41 ₽ — скидка постоянного клиента 5 %; с --discount — бо́льшая из двух
python -m sandbox 3x100 --code   # 300.00 RUB — код валюты вместо «₽», см. «Флаги»
python -m sandbox --version   # sandbox 0.1.0
```

Команды, CI и критичные зоны — в профиле [docs/agents/](docs/agents/).


Цена позиции — неотрицательная, не точнее копейки (`1x0.005` — ошибка, без округления), до 15 цифр (вместе с копейками). Пример: `python -m sandbox 1x-5` → `sandbox: error: цена не может быть отрицательной`, код 2.

Минимальная сумма заказа — 300 ₽ после скидки: заказ меньше — ошибка `sandbox: error: минимальная сумма заказа — 300.00 ₽` и код 2, ровно 300 ₽ проходит (`3x100 --discount 1` — ошибка, `3x100` — `300.00 ₽`). С `--loyal` сравнивается итог после скидки постоянного клиента. Пример: `python -m sandbox 2x150 --kop` → `30000`.

## Флаги

- `--code` — вместо знака «₽» печатается код валюты `RUB` через обычный пробел: `python -m sandbox 3x100 --code` → `300.00 RUB`. Разделитель тысяч остаётся неразрывным пробелом. С `--kop` несовместим: ошибка и код 2. Пример с разделителем тысяч: `python -m sandbox 1x1000 --code` → `1 000.00 RUB`.
- `--avg` — второй строкой после итога «средняя цена: X»: итог со скидкой, делённый на сумму количеств, до ближайшей копейки, половина — вверх (`1x300.01 1x0.02 --avg` → `150.02 ₽`). Формат суммы — как у итога (`--kop`, `--code`). С `--count` строка «позиций» идёт третьей.
