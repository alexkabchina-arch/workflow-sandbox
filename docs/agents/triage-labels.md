# Метки triage

Скиллы Мэтта говорят пятью каноническими ролями; в этом трекере метки называются так же.

| Роль в mattpocock/skills | Метка в трекере   | Значение                                              |
| ------------------------ | ----------------- | ----------------------------------------------------- |
| `needs-triage`           | `needs-triage`    | Нужна оценка владельца                                |
| `needs-info`             | `needs-info`      | Ждём информацию от автора                             |
| `ready-for-agent`        | `ready-for-agent` | Полностью описан, агент может брать                   |
| `ready-for-human`        | `ready-for-human` | Нужен человек: решение или действие владельца         |
| `wontfix`                | `wontfix`         | Делать не будем                                       |

`ready-for-human` — это и **очередь решений** ([GLOSSARY.md](https://github.com/alexkabchina-arch/workflow/blob/v2026.10.01.12/GLOSSARY.md)): вопрос, варианты, последствия, что сделано по умолчанию, рекомендация. Ответ владельца — комментарий и метка `ready-for-agent`.

## Вне пяти канонических

| Метка         | Значение                                                        |
| ------------- | --------------------------------------------------------------- |
| `in-progress` | Тикет взят в работу; ставит сессия при старте, снимает при мёрже |
