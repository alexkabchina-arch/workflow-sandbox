# Скиллы Мэтта Покока (github.com/mattpocock/skills), которые канон ставит в проект.
#
# Принцип (decisions.md, «Скиллы Мэтта»): ставим только шаг процесса или то, что владелец
# вызывает сам; у каждого скилла — причина. Версия — коммит `main` Мэтта в `matt-skills.lock.json`
# рядом. Оба файла вендорятся и лежат под `.canon.lock`: руками в проекте не править.
# Ставит `canon-sync` (через `npx skills`), обновляет `matt-skills-update` канона отдельным PR.
# Новые скиллы Мэтта добавляются сюда только по решению владельца.
#
# Формат: `<имя> — <причина>`, одна строка на скилл.

grill-with-docs — гриллинг плана с записью глоссария и ADR; владелец вызывает сам
grilling — гриллинг плана или решения; на него опираются grill-with-docs, triage и wayfinder
domain-modeling — глоссарий и ADR проекта; на него опирается grill-with-docs
to-spec — шаг процесса: обсуждённое — в спеку в трекере
to-tickets — шаг процесса: спека или план — в тикеты с блокирующими связями
triage — шаг процесса: разбор входящих тикетов и бриф для агента
wayfinder — шаг процесса: большая работа — картой тикетов-решений
implement — шаг процесса: работа по тикету или спеке
implement-spec — шаг процесса: реализация спеки, нарезанной to-spec и to-tickets
tdd — шаг процесса: тест вперёд; его вызывает implement
diagnosing-bugs — шаг процесса для трудных багов и регрессий производительности
code-review — ревью по стандартам репозитория и тикету; его вызывает implement
pr — тело PR (шаг 5 /ship)
retro — ретро сессии: уроки процесса вместо журнала (CONTEXT.md)
writing-for-agents — правка скиллов, CLAUDE.md и AGENTS.md
setup-matt-pocock-skills — разовая настройка трекера, меток и доков для остальных скиллов; файлы — в профиле
