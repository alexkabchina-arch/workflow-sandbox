# Карта функций приложения

Какие функции есть у приложения и как до каждой добраться командой инструмента проверки
(`tools/verify/tool.py`, вывод — JSON). Карту и инструмент `/verify` берёт из `main`: они —
пути-ограничители. Новая функция приложения — строка здесь.

| Функция | Что делает | Команда |
|---|---|---|
| `версия` | приложение запускается, печатает версию | `tool.py doctor` |
| `сумма` | итог заказа по позициям КОЛxЦЕНА | `tool.py total 3x100 1x49.90` |
| `скидка` | итог со скидкой, % | `tool.py total 3x100 --discount 10` |
| `постоянный клиент` | скидка постоянного клиента, с `--discount` — бо́льшая | `tool.py total 3x100 --loyal` |
| `копейки` | итог целым числом копеек | `tool.py total 3x100 --kop` |
| `код валюты` | итог с «RUB» вместо «₽» | `tool.py total 3x100 --code` |
| `позиции` | строка «позиций: K» после итога | `tool.py total 3x100 --count` |
| `средняя цена` | строка «средняя цена: X» | `tool.py total 3x100 --avg` |
| `округление` | итог до целого рубля, половина — вверх | `tool.py total 1x100.50 --round` |
| `минимум заказа` | заказ меньше минимума — ошибка ввода (`exit` 2) | `tool.py total 1x1` |

Ошибка ввода приложения — ответ инструмента с `exit` и `error`, а не сбой. Пробный режим —
`tool.py --dry-run <команда>`: что было бы запущено. Разрушающих команд нет: приложение ничего не
пишет. Копии прода у приложения нет — данных нет, проверка идёт на вводе команды.
